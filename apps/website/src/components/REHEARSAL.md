# Portfolio scenes

Plan: still illustrations above the existing feature content, at the portfolio's 825px content width. The focal object is a terminal or workflow excerpt; the payoff is a useful tool or a shared contribution. No playback or imitation inputs.

Reference: stageshow `static-card`. Kept its bottom bleed, quiet window chrome, and one foreground satellite. Adapted the native Window chrome into SceneWindow and replaced the customer table with portfolio-specific copy and Lucide icons. The illustrations inherit the website's dark/light surface and accent tokens.

Placement: Home and About introduce the terminal profile; Projects highlights create-cf-token; Packages shows the published profile command; Open Source illustrates the contribution process without inventing a real PR or its status.

Compact design: at 600px and below the window fills the column and the satellite moves below the meaningful content. Text retains its size rather than scaling the entire scene. The stage clips only the lower filler region.

Captured and visually reviewed: standalone server-rendered compositions at 920px and 390px viewport widths, all four variants, with a light-theme profile sample. The phone review confirmed whole commands, headings, and satellite labels. These are stills, so reduced motion and the poster have the same composition.

Not checked: authenticated/local Cloudflare runtime, full-page browser captures, all variants in light theme, or the stageshow film gate. Captures used system font fallbacks; the production site supplies Source Sans 3 and Syne.
