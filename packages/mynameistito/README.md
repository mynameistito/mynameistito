# mynameistito

An OpenTUI portfolio for Tito's GitHub projects, npm packages, and links.

```bash
npx mynameistito
```

```bash
bunx mynameistito
```

## Exports

```ts
import { links, packages, profile, projects } from "mynameistito";
```

## Development

```bash
bun install
bun --filter mynameistito run dev
```
